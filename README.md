🚀 Blast Puzzle Prototype (Cocos Creator + TS)
Краткое описание: Динамичный прототип игры в жанре "Blast" с акцентом на чистую архитектуру и сочный игровой процесс. Проект подготовлен как тестовое задание, но расширен до полноценного игрового вертикального среза (Vertical Slice).
🛠 Технологический стек
Engine: Cocos Creator 2.4
Language: TypeScript
Patterns: MVC (разрыв логики и отображения), Command, Observer, Factory.
Principles: SOLID, OOP.
🌟 Что реализовано (Scope)
Базовый функционал:
✅ Генерация адаптивного поля

.
✅ Алгоритм поиска групп (Flood Fill) и механика сжигания.
✅ Реалистичное падение тайлов и заполнение пустот сверху.
✅ Система подсчета очков и ходов с условиями Win/Lose.
Дополнительные "сочные" фичи:
🔥 Super Tiles: При сборке группы
создаются спец-тайлы (линейные бомбы / область).
💣 Boosters: Реализованы механики "Бомба" и "Телепорт".
🔄 Smart Shuffle: Автоматическое перемешивание поля, если нет ходов (до 3 раз).
✨ Juice & Polish: Плавные анимации появления, уничтожения и перемещения без использования физического движка.
🏗 Архитектурные решения
Для обеспечения масштабируемости я разделил проект на четкие слои:
Core Logic (Pure TS): Независимая от движка логика поля, поиска групп и мат-модели. Легко покрывается Unit-тестами.
View Layer (Cocos): Отвечает только за рендеринг, анимации (Tween) и ввод пользователя.
Command System: Все действия (взрыв, перемешивание, бонус) вынесены в отдельные команды, что позволяет легко добавлять новые механики.
